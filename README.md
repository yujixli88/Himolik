# Himolik: виртуальная лаборатория по химии и физике

FastAPI (бэкенд) + чистый HTML/CSS/JS (фронтенд в `static/`) + ИИ-лаборант на Gemini.
Учитель создаёт комнату с реагентами или приборами и получает код и QR. Ученики заходят по коду, проводят опыты и спрашивают Химолика.

## Секреты: куда их вписывать
Ключи **нельзя** записывать ни в один файл проекта (`render.yaml`, `main.py`, `README.md`, `.env.example` и т. д.): всё, что в проекте, уходит на GitHub.
Ключи задаются только переменными окружения:

| Переменная | Что это |
|---|---|
| `GEMINI_API_KEY` | ключ из Google AI Studio |
| `SECRET_KEY` | любая длинная случайная строка (подпись токенов) |

Сгенерировать `SECRET_KEY`:
```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```
Если ключ или `SECRET_KEY` попали на скриншот или в GitHub, удалите их и создайте новые.

## Запуск на своём компьютере (Windows, PowerShell)
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
$env:GEMINI_API_KEY="ваш_ключ"
$env:SECRET_KEY="ваша_случайная_строка"
uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000. Переменные `$env:...` действуют только в этом окне терминала: после перезапуска терминала введите их снова.
Без `GEMINI_API_KEY` сайт работает, но Химолик отвечает, что недоступен.
Тесты: `python -m unittest discover -s tests -t .`

## Деплой на Render (бесплатно, без домена)
1. Загрузите проект в репозиторий на GitHub. Перед этим поиском по проекту (Ctrl+Shift+F) убедитесь, что в файлах нет ключей.
2. Render: **New → Blueprint**, выберите репозиторий. Render прочитает `render.yaml` (команды запуска и версию Python).
   Либо **New → Web Service**: Build `pip install -r requirements.txt`, Start `uvicorn main:app --host 0.0.0.0 --port $PORT --proxy-headers --forwarded-allow-ips="*"`.
3. Откройте сервис → **Environment** → **Add Environment Variable**:
   - Key `GEMINI_API_KEY`, Value: ваш ключ (только ключ, без названия);
   - Key `SECRET_KEY`, Value: случайная строка (если Render не создал её сам).
   Раздел «Environment Groups» не нужен.
4. Нажмите **Save**: сервис перезапустится. Публичная ссылка вида `https://имя.onrender.com` открывается с любого телефона, QR ведёт сразу в комнату.

## Как пользоваться
- **Педагог:** «Я педагог» → предмет, название, отметить реагенты или приборы → «Создать комнату» → показать QR или назвать код. Список учеников и их прогресс обновляется сам.
- **Ученик:** отсканировать QR или ввести код и имя (фамилия не нужна) → «Подойти к столу» → нажимать реагенты, смотреть реакцию → спрашивать Химолика.

## Защита ИИ
Ключ только в переменных окружения и уходит лишь в Google. Контекст опыта строит сервер. Вопрос ученика трактуется как данные, а не команды. Очевидные «взломы» отсекаются до обращения к Gemini. Модель отвечает `{on_topic, answer}`, а при `on_topic=false` показывается заготовленный отказ. Есть фильтры безопасности Gemini, лимиты по ученику, комнате и всему серверу, запасные модели, журнал вопросов для учителя. Имена учеников в Gemini не передаются.

## Что важно знать
- **Бесплатный Render засыпает** примерно через 15 минут без запросов, первый вход после паузы может занять до минуты. Откройте сайт заранее перед показом.
- **Комнаты хранятся в памяти:** при перезапуске сервера они пропадают, и ученикам нужно войти заново.
- **Бесплатный тариф Gemini:** по условиям Google запросы могут использоваться для улучшения их продуктов. Не вводите в чат личные данные детей.
- **Модели Gemini** меняются: проверьте актуальные имена в AI Studio и при необходимости задайте `GEMINI_MODELS` (список через запятую).
- **Правила вёрстки:** сервер блокирует inline-скрипты, inline-стили и CDN. Всё лежит в `static/` (см. `docs/API.md`).
- Для заявки на конкурс заготовка AI-карты: `docs/AI_CARD.md`.
