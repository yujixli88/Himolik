# Himolik: виртуальная лаборатория (бэкенд)

FastAPI + Gemini. Химия и физика, комнаты по коду и QR, ИИ-лаборант с жёсткими ограничениями. Фронтенд кладётся в `static/` (см. `docs/API.md`).

## Запуск локально
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впишите GEMINI_API_KEY, затем:
export $(grep -v '^#' .env | xargs)    # Windows: задайте переменные вручную в PowerShell
DEBUG=true uvicorn main:app --reload
```
Откройте http://127.0.0.1:8000. Тесты ядра: `python -m unittest discover -s tests -t .`

## Деплой на Render (бесплатно, без домена)
1. Залейте папку в GitHub (`.env` в репозиторий не попадёт: он в `.gitignore`).
2. Render → **New → Blueprint** → выберите репозиторий (подхватится `render.yaml`). Или **New → Web Service** с командами из `render.yaml`.
3. В разделе **Environment** задайте `GEMINI_API_KEY` (ключ из Google AI Studio). `SECRET_KEY` Render создаст сам.
4. Через пару минут появится ссылка `https://<имя>.onrender.com`. Она работает с любого телефона, а QR ведёт сразу в комнату.

## Защита ИИ
Ключ только в переменной окружения и уходит лишь в Google. Ученик не может менять инструкции: контекст опыта строит сервер. Вопрос идёт как «недоверенный текст». Очевидные «взломы» отсекаются до обращения к Gemini. Ответ приходит в формате `{on_topic, answer}`, и при `on_topic=false` показывается заготовленный отказ. Включены фильтры безопасности Gemini. Есть лимиты по ученику, комнате и всему серверу, цепочка запасных моделей и журнал вопросов для учителя. В Gemini не передаются имена учеников.

## Что важно знать
- **Бесплатный Render засыпает** примерно через 15 минут без запросов, первый заход тогда идёт до минуты. Перед демонстрацией откройте сайт заранее. Комнаты хранятся в памяти; после перезапуска сервера клиент восстанавливает их сам (`restore` / `join` со снимком).
- **Бесплатный тариф Gemini:** по правилам Google, запросы могут использоваться для улучшения их продуктов, а лимиты смотрите в AI Studio. Дети и личные данные в чате нежелательны (подсказка об этом есть в `docs/API.md`). Для реальных школ нужен платный тариф.
- **Имена моделей** меняются: проверьте актуальные в AI Studio и при необходимости задайте `GEMINI_MODELS`. После финальной проверки лучше закрепить конкретные версии.
- Для заявки (Положение, Приложение 2) заготовка AI-карты лежит в `docs/AI_CARD.md`.
