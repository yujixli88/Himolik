Модули backend

  • app/main.py — запуск FastAPI и API-маршруты
  • app/catalog.py — каталог предметов и событий
  • app/simulator.py — модель опытов
  • app/rooms.py — комнаты и ученики
  • app/ai.py — интеграция с ИИ-лаборантом
  • app/security.py — токены и ограничения запросов
  • app/config.py — настройки приложения
  • app/qr.py — генерация QR-кодов

Это перечень модулей, а не просмотр исходного кода. Исходники открывайте в VS Code или GitHub; не публикуйте файлы сервера через сайт.
